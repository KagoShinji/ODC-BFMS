# Barangay Financial Management System by ODC — Implementation status

The repository contains a runnable, branded application and a Supabase-ready foundation. A project URL and publishable key are configured locally, with `DATA_PROVIDER=supabase` enabled. The project owner applied the initial finance and system administrator migrations. A super admin Auth account was created, assigned the global role, and verified through normal Supabase sign-in and role reads. Authorized users can open a read-only workspace preview with sample records; live financial posting remains gated, and no official barangay finance dataset is connected.
